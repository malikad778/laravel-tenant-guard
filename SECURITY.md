# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Laravel Tenant Guard, please send an e-mail to Malik Adnan at `contact@codebyadnan.tech`.

All security vulnerabilities will be promptly addressed and disclosed responsibly.
